# 密度、版式与图表选择

## 判断无效留白

先看页内信息是否过少、上下脱节、列宽不合理或段距过大。正文持续只占上半页时，优先合并相关内容、缩短段距或改变图文布局；有实际解释价值时才加入图表。不要仅为填空而编造数据、科学图或装饰图。封面和章节扉页可保留更多空白。

对于紧凑方案，正文通常让信息区域延伸到版心高度的约70–85%；这只是诊断参考，不按像素强凑占用率。保持标题、正文、图表和结论之间的呼吸空间。最终以实际阅读效果、字号、段落完整性和打印检查为准。

## 版式库

| 内容 | 适合布局 |
|---|---|
| 产品或观点介绍 | 非对称图文、编号论点、下方证据图 |
| 操作步骤 | 横向步骤带＋纵向确认点，或泳道图 |
| 功能与范围 | 三列表格＋架构示意＋范围边界 |
| 数据比较 | 分组条形图＋关键解释＋原始数值表 |
| 时间与变化 | 甘特图或折线图，旁列阶段产物 |
| 原理与科学 | 有标注的结构图、流程图、因果图；说明概念/实测边界 |
| 验收与决策 | 验收矩阵＋检查路径＋下一步行动 |

同一份文档按内容混用版式，不把每页都写成三条清单加引言框。A4适合组合两种有关联的模块；PPT将复杂组合拆成多页，避免为了页数缩小字号。HTML图表在手机上保持可读：过宽图可横向滚动并提供说明，不无限缩小文字。

## 图表规则

- 先有问题，再选图。比较用条形/柱状，时间序列用折线，阶段排期用甘特，关系用流程或结构图。
- 所有数值图明确单位、图例、数据来源及时间范围。演示数据标注“演示假设，非实测”；目标曲线写“建议计划，非完成结果”。无数据时使用非数值结构图，或省略图表。
- 柱形基线从0起，轴范围覆盖数据，刻度合理。折线不要靠截断轴夸大变化。颜色不能是唯一识别方式。
- 统一0.5–0.8pt浅灰网格、1.2–1.7pt主线，陶土色强调当前系列，橄榄灰为对照；无3D、重阴影或渐变网格。
- 保存原始数据。Word中的数值图旁可提供原生数据表；PPT使用可编辑图形或原生图表，并说明可编辑范围。
- 示例脚本仅预置本方案的四阶段时间比较、六周计划等结构；换数据后必须调整轴与布局，不把固定轴或阶段数视为通用算法。
