# 格式实现与验收

## 共同内容

保留一份 JSON 或 Markdown 内容源。PDF和Word共享章节内容，PPT可浓缩但不引入无来源的新结论。示例数据与真实业绩分开标注。

## DOCX

原生段落、Heading 1/2、表格、页眉页脚及页码域。显式设置A4、字体和东亚字体，不将正文转图片。对可编辑文档设置实际段落间距、keepNext与表格重复表头。Word 页面背景在不同阅读器或打印设置可能不同，需渲染核验；背景缺失时正文仍可读。若 Word/LibreOffice 不可用，明确只做了结构验证。

## PDF

嵌入中文字体，确认文本可提取、页数和页面大小正确。可以由经过核验的 Word 或独立印刷版导出，但说明二者可能有细微行距差异。

## PPTX

原生可编辑文本框、线条、表格及图形；线稿可作为图片，但整页不能栅格化。当前V2示例把主题插画和数据图转为可编辑图形、线条和文字；这不等同于带Excel数据表的原生Chart对象。若用户需要编辑图表数据后自动更新，用原生Chart并嵌入数据表。使用16:9布局，实际导出预览后检查每页。

## HTML

语义化标题、段落、表格，嵌入SVG线稿，离线可用。窄屏重新排版，表格可横向滚动。打印CSS设置A4与合理分页；正式PDF应走经过核验的导出路径。下载链接必须有真实文件，不设置空按钮。

## 可复用脚本与环境

先运行 `python scripts/bootstrap.py`，再运行 `python scripts/run.py`。build.py 支持 `--input`、`--out`、`--name`、`--node`、`--node-modules`、`--font-dir`。示例为六页阅读稿、八张演示稿。数据源保留charts，品牌与插画使用identity、visuals及外部scene JSON。示例中的轴范围、阶段数量和表格内容按该方案设计，换任务需重设，不能冒充全自动通用排版。生成后检查页界、分页和真实渲染。默认字体为 assets/fonts/serif.ttf 与 body.ttf，跨平台随仓库提供。Office 应安装两款字体，并检查实际分页。

## 交付验收

- 实际打开四种成品；检查文件有效且无空页。
- 全页渲染：中文无方框、无裁切、表格不越界、无孤立标题。
- 确认可编辑性：DOCX包含段落/表格，PPTX包含文本框而非整页截图。
- 确认精美来自比例、留白、细线、字体层级与统一色彩，不能仅以“加了橙色”判定达标。
- 保存对比图和检查记录，区分已验证、主观评价及未验证事项。
