# 暖纸与墨线

视觉哲学：纸面为阅读留出时间。大标题采用有书卷感的衬线字体，以疏密和比例建立节奏。细线连接信息，陶土色只点亮关键的词、编号与转折。插画从书页、纸张、植物和路径中抽取结构；线条略有有机弯曲，但文字和版心始终严格对齐。

## 主题 tokens

| 名称 | 值 | 用法 |
|---|---|---|
| paper | #FAF9F5 | 页面底色 |
| wash | #EFE9DE | 引言、浅色区域 |
| ink | #292923 | 标题与主文字 |
| muted | #68665F | 辅助文字 |
| accent | #CC785C | 插画填色、装饰、较大编号 |
| accentText | #A9583E | 小号强调文字与链接 |
| rule | #CFC7B9 | 非交互分隔线 |
| olive | #898875 | 少量植物与细节 |

标题使用随附的 Editorial Serif SC（Noto Serif SC 静态衍生版），正文使用 Editorial Sans SC（Noto Sans SC 静态衍生版）；两款字体保留 OFL 许可。不可假装使用未授权的 Copernicus / Tiempos。小号文字使用 ink、muted 或 accentText；装饰用 accent 不直接等同于正文色。

## 排版

- A4：210×297mm，左右版心约 18–22mm；正文 10.5–11.5pt，行距 1.5–1.65。封面标题 30–38pt，章标题 24–28pt。
- PPTX：16:9，安全边距至少 0.5英寸，标题 28–38pt，正文通常不低于 18pt，脚注可小于正文。按讲述重新分配内容。
- 页眉：左侧统一品牌标记＋字标＋小号描述，右侧文种/章节；下面0.5–0.75pt细线。标记约24–32px，标记和标题之间有明确间距，不用大段空白撑开页眉。页脚：简化品牌、版本/出处、页码与总页数。网页导航和下载按钮共用这套线宽、字体与颜色。
- 一个页面通常一个主论点；长文可自然分页。标题与后段同页，短表格不拆行，续表重复表头。表格用低对比表头底色、细横线，避免黑色网格。
- 连续正文保持可读密度，避免为“留白”删掉关键内容。对齐左边缘，章节编号、引言和小型图注形成节奏。

## 插画

使用按当次主题原创的SVG / 向量线稿，详见art-direction.md。笔画约1–1.6pt，墨色或橄榄灰；主物体1–3个，陶土色局部填充，搭配少量星芒、路径、纸夹、注释或圆点。不要固定使用书本长植物；同一项目可复用同一主题素材保持一致，但不同主题应重新构思。

正文密度与图表选择见layouts.md。减少上下脱节的空白，混用图文、表格、结构示意与有来源的数据图；不以编造图表填空。
